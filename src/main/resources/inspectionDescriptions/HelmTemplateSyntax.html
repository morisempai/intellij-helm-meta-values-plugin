Reports template expressions that cannot be parsed:
  • an unclosed {{, or a stray }};
  • an empty expression, unbalanced parentheses, an unterminated string;
  • a | with nothing on one side of it, as in {{ .Values.host | }};
  • an assignment with no value, as in {{ $name := }};
  • if, range, with, define or block with nothing to act on, and end or a plain else given an argument;
  • a block action that does not pair up with its end.

Only structure is checked. An expression this plugin cannot evaluate is not an expression that is wrong: include, b64enc, .Release.Name and a chart's own helpers are all valid and beyond the evaluator, so nothing is said about them. An unknown function name is never reported either, since it may be a helper defined elsewhere.
