Reports template expressions that cannot be parsed: an unclosed {{, a stray }}, unbalanced parentheses or quotes, an empty expression, and block actions (range, if, with, define, block) that do not pair up with their end.

Only structure is checked. An expression this plugin cannot evaluate is not an expression that is wrong: include, b64enc, .Release.Name and a chart's own helpers are all valid and beyond the evaluator, so nothing is said about them. An unknown function name is never reported either, since it may be a helper defined elsewhere.
