Reports a variable that some, but not all, of the configured meta values files define.

This is useful when the meta files are parallel environments — dev.yaml and prod.yaml describing the same variables with different values — where a gap means the variable was added to one environment and forgotten in another. The quick fix adds it to each file that is missing it.

It is off by default, because meta files are just as often complementary, each contributing its own set of keys. In that arrangement every variable is missing from all the other files by design and the report is pure noise.
