Reports {{ .Values.* }} expressions in templated Helm values files whose path is not defined in the configured meta values file. Every expression in the file is checked, including those the YAML parser cannot represent, such as a bare {{- if ... }} line or a template used as a key; expressions inside comments are skipped.

Setting a variable root narrows this to one branch of the tree — with global, only {{ .Values.global.* }} is checked.

One softer signal is reported as a weak warning: the path resolves to a mapping while the expression uses it as a plain value. Expressions that consume structures, such as toYaml or range, are ignored.

A variable defined in only some of several meta values files is not reported here. That is a separate, opt-in inspection, Helm global variable missing in some meta values files.

The inspection is inactive until a meta values file resolves. Configure it under Settings | Tools | Helm Global Variables, or place a .helm-globals.yaml file in the project root.
